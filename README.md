## 🚀 Proyectos destacados

### [SmartFISEI — Sistema de Gestión Académica](https://github.com/JeampyON/ProyectoFinal_Estructuras_Grupo04)

Proyecto académico grupal para gestionar trámites y servicios de la FISEI.
Integra estructuras de datos como colas, pilas, listas, árboles y grafos
en una aplicación web desarrollada con Django.

**Tecnologías:** Python · Django · Estructuras de datos

### [CineScope — Catálogo de películas y series](https://github.com/MateoRonquillo/MyCdS-Proyecto)

Proyecto colaborativo para explorar un catálogo de películas y series.
Incluye búsqueda, filtros, ordenamiento, detalles, favoritos y preferencias
guardadas en el navegador.

**Tecnologías:** JavaScript · HTML · Sass · LocalStorage
